# Glossário

## Abstração

Técnica de esconder detalhes desnecessários para focar apenas no que é relevante.

## Acoplamento

Nível de dependência entre módulos ou componentes.

## Algoritmo

Sequência de passos para resolver um problema.

## Complexidade

Dificuldade de compreender, modificar ou executar uma solução.

## Correção

Capacidade de um programa produzir os resultados esperados.

## Estado

Conjunto de informações armazenadas por um sistema em determinado momento.

## Modularidade

Organização do software em partes independentes.

## Programação Estruturada

Paradigma que utiliza estruturas claras de controle para reduzir a complexidade.

## Responsabilidade Única

Princípio segundo o qual cada módulo deve possuir apenas um motivo para mudar.

## Separação de Responsabilidades

Divisão clara das funções de cada parte do sistema.
