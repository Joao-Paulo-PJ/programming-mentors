# Fundamentos de Pensamento de Software com NotebookLM

## Contexto

Este projeto documenta meu processo de aprendizagem utilizando o Google NotebookLM para estudar fundamentos de engenharia de software e pensamento computacional.

O foco inicial foi compreender as ideias de Edsger W. Dijkstra e outros pesquisadores que influenciaram a forma como software é projetado, organizado e mantido.

Em vez de estudar apenas linguagens e frameworks, o objetivo é desenvolver habilidades de raciocínio que possam ser aplicadas em qualquer tecnologia, incluindo Node.js, TypeScript e React.

---

## Objetivos de Estudo

* Aprender a pensar em soluções antes de escrever código.
* Desenvolver clareza na modelagem de problemas.
* Entender princípios de modularidade e abstração.
* Melhorar a capacidade de analisar código e arquitetura.
* Construir uma base de conhecimento reutilizável utilizando NotebookLM.
